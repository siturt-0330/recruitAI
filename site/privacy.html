らくらくエントリー プライバシーポリシー

最終更新日：2026年10月16日

らくらくエントリー（以下「本拡張機能」）は、就職活動の応募フォームに、利用者が登録したプロフィールを自動で入力する Chrome 拡張機能です。 本ポリシーでは、本拡張機能が扱う情報と、その取り扱いについて説明します。

1. 利用者の端末の中だけに保存する情報

氏名・生年月日・住所・電話番号・メールアドレス・学歴・顔写真など、利用者が登録したプロフィールは、 利用者のブラウザ内（Chrome の拡張機能ストレージ）にだけ保存します。運営者のサーバーや第三者に送信することはありません。

利用者が保存した就活サイトのマイページのログイン情報（URL・ID・パスワード）も、同じくブラウザ内にだけ保存し、 利用者がそのマイページを開いたときにログイン欄へ入力するためだけに使います。ログインボタンを自動で押すことはありません。

2. 運営者のサーバーに送信する情報

「ルール + Sophon」がオンのとき、ルールだけでは判定できなかった入力欄について、どのプロフィール項目に当たるかを AI で判定します。 その際、次の情報を運営者のサーバー（Cloudflare Workers）に送信します。

入力欄の構造入力欄の見出し・ラベル・プレースホルダー・name 属性・選択肢など。入力されている値やプロフィールの内容は含みません。ページの URL も送りません。
インストール ID本拡張機能をインストールしたときに作るランダムな ID。1日の利用回数の制限に使います。個人を特定する情報は含みません。
IP アドレス通信の性質上サーバーに届きます。不正な大量利用を防ぐための1日ごとの回数の集計にだけ使い、日付が変わると集計から消去します。

入力欄の構造は、判定のために OpenAI の API に送信されます。OpenAI での取り扱いは OpenAI のポリシーに従います。 運営者は入力欄の構造を保存しません（障害の調査のため、件数などの記録を一時的に残すことがあります）。

「ルールのみ」に切り替えると、サーバーへの送信は一切行いません。

Web 版（マイページ管理）

Web 版（app.rakuraku-entry.com）に登録した会社・メモ・プロフィールは、利用者のブラウザ内（localStorage）にだけ保存し、運営者のサーバーには送信しません。 パスワードは Web 版には保存せず、拡張機能の中にだけ保存します（Web 版の画面で入力したパスワードも、そのまま拡張機能に渡して保存し、Web 版には残しません）。

会社のロゴを表示するため、会社名またはその会社のサイトの URL を運営者のサーバーに送信します。サーバーは、公開データベースの Wikidata で会社名から公式サイトを調べ、そのサイトのアイコンを取得します。サイトから取得できないときは、Google のファビコン配信にそのサイトのドメインを渡して取得します。 会社名と URL 以外の情報は送信しません。 取得したロゴは、同じ会社について何度も取得しないよう一時的に保存します。

3. 広告（PR）について

本拡張機能のポップアップには、「PR」と表示した広告枠があります。広告の内容は運営者のサーバーから取得しますが、 その際に利用者の情報は送信しません。広告をクリックしたときに表示されるページでの情報の取り扱いは、各広告主のポリシーに従います。

4. 利用目的

取得した情報は、応募フォームの入力欄の判定と、サービスの不正利用の防止のためにだけ使います。販売や、広告のための利用者の追跡には使いません。

5. 情報の削除

本拡張機能をアンインストールすると、ブラウザ内に保存したプロフィールなどの情報はすべて削除されます。
