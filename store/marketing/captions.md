## リール・TikTok・ショート用の縦型動画

動画は `reel.mp4`（1080×1920、22.5秒、音なし）。ストア公開前は、最後が「近日公開」になる `reel-soon.mp4` を使う。表紙は `reel-cover.png`。

- 音は入れていない。投稿するアプリの中の音源（著作権の心配がないもの）を付ける
- 下の約 400px と右端はアプリのボタンや説明文に隠れるので、大事な文字は置いていない
- 作り直すときは `reel.html` を直して書き出す（`?soon` を付けると近日公開版）

```bash
node store/marketing/capture.mjs store/marketing/reel.html store/marketing/reel.mp4 --muxer=<mp4-muxer の build/mp4-muxer.js>
node store/marketing/capture.mjs store/marketing/reel.html store/marketing/reel-cover.png --t=2.3
```

## 投稿のコツ

- 1枚目（つかみ）が勝負。保存やシェアされやすいのは「あるある」系の問いかけ
- 投稿はインターン応募が増える時期（夏前・秋）と、本選考が始まる3月前後に集中させる
- 画面収録の短い動画（フォームが一瞬で埋まる様子）をリールで出すと、静止画より伸びやすい
- ストアに公開されてから投稿する（それまでは「近日公開」に書き換える）
