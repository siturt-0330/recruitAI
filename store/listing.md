## 説明

**1.1.3 の審査が通ってから差し替える。** 審査中に変えると、審査を取り消して出し直すことになる。
最初の数行で「何が楽になるか」と「データを外に出さない」を伝える。検索されやすい言葉（就活・エントリーシート（ES）・応募フォーム・インターン・本選考・自動入力・マイページ・ID・パスワード）は自然な文の中に入れ、言葉を並べるだけにはしない（ストアの規約で、関係のない言葉や言葉の羅列は禁止）。ほかの就活サイトの名前は入れない。

就活のエントリーシート（ES）や応募フォームの入力を、ワンクリックで。
氏名・フリガナ・住所・学歴など、企業ごとに何度も打つ同じ内容を、一度の登録で自動入力する Chrome 拡張機能です。登録した情報は、あなたのブラウザの中にだけ保存します。

インターンも本選考も、エントリーの数だけ同じ入力がくり返されます。らくらくエントリーなら、応募フォームを開いてアイコンを押すだけ。浮いた時間を、志望動機や面接の準備に使えます。

■ 3 つの特長
1. ワンクリックで入力：企業ごとに形の違う応募フォームでも、項目を見分けて入力します
2. 入れたところがひと目で分かる：入力した欄に「済」、自信がない欄に「確認」の印。送信前にそこだけ見直せば大丈夫です
3. データを外に出さない：プロフィールとマイページのパスワードは、あなたのブラウザの中だけに保存します

■ 入力できる項目
・氏名、フリガナ、ローマ字、生年月日、性別
・住所（郵便番号・都道府県・市区町村・番地・建物名）、帰省先、緊急連絡先
・電話番号、メールアドレス
・学校区分、大学名、学部・学科、入学・卒業年月、高校
・運転免許、TOEIC などの資格、趣味・特技 など

■ フォームに合わせて自動で変換
・和暦／西暦、全角／半角、カタカナ／ひらがな
・電話番号や郵便番号の分割欄、ハイフンのあり・なし
・年・月・日が分かれたプルダウンや、デザインされた独自のプルダウン

■ 送信は自分で
入力するだけで、送信ボタンは押しません。「元に戻す」で入力前の状態にも戻せます。

■ AI「Sophon」が判定を手伝います
ルールで分からなかった欄だけ、AI が見出しから判断します。API キーの設定は不要で、そのまま使えます。

■ マイページの ID・パスワードもまとめて管理（新機能）
受けている会社のマイページを、Web 版（app.rakuraku-entry.com）で一覧にまとめられます。ログイン画面でアイコンから ID とパスワードを保存するか、Web 版の会社ページで入力しておけば、一覧から押すだけで、ID とパスワードが入った状態でマイページが開きます。何十社ぶんのログイン情報を、メモ帳や表計算で管理する必要はありません。
まだ入力を許可していないサイトは、開いたときに出る小さな画面で許可すれば、そのまま入力されます。ログインボタンは自分で押すので、勝手にログインすることはありません。

■ プライバシー
プロフィールとマイページのパスワードは、あなたのブラウザの中にだけ保存します。Web 版の画面で入力したパスワードも、そのまま拡張機能に渡して保存し、Web 版や運営者のサーバーには残しません。AI の判定に送るのは入力欄の見出しだけで、名前や住所などの中身は送りません。

■ 使い方
1. アイコンから「プロフィールを作成」で登録
2. 応募フォームを開いて、アイコンの「このページに入力」（または Alt+Shift+F）
3. マイページのログイン画面では、アイコンから「保存」（Web 版の会社ページでも入力できます）。次からは Web 版の一覧から開けます

■ よくある質問
Q. 無料ですか？
A. 現在はすべての機能を無料で使えます（今後、有料プランを追加する予定です）。
Q. どのブラウザで使えますか？
A. パソコン版の Google Chrome と、Chrome の拡張機能に対応したブラウザで使えます。スマホでは使えません。
Q. 入力した内容は、どこかに送られますか？
A. プロフィールとパスワードは、どこにも送りません。AI の判定に送るのは入力欄の見出しなどだけです。

## 単一用途の説明（Single purpose）

就職活動の応募フォームと、応募先企業のマイページのログイン画面に、利用者が登録した情報（プロフィール・ログイン情報）を自動で入力すること。

## 権限の理由

ダッシュボードの「プライバシー」タブにある欄ごとに貼る。コンテンツスクリプト専用の欄はなく、ホスト権限の欄にまとめて書く（ホスト権限は permissions と content_scripts のマッチパターンをまとめて指す）。

### activeTab が必要な理由

利用者がアイコンかショートカットで入力を指示したタブにだけ、入力処理を実行するために使います。

### scripting が必要な理由

利用者が指示したタブの応募フォームやマイページのログイン画面を読み取り、入力するスクリプトを実行するために使います。

### storage が必要な理由

利用者が登録したプロフィール・設定と、マイページのログイン情報（ID・パスワード）を、利用者のブラウザ内に保存するために使います。運営者のサーバーには送信しません。

### ホスト権限が必要な理由

次の3つのために使います。
1. ルールで判定できなかった入力欄について、運営者の API（api.rakuraku-entry.com）で AI 判定を行うため。送信するのは入力欄の見出しなどの構造だけで、プロフィールの内容は送信しません。
2. 運営者の Web 版（app.rakuraku-entry.com）のページでだけコンテンツスクリプトを動かし、拡張機能に保存した会社の一覧をページに表示し、ページから「マイページを開く」の指示と、利用者が Web 版で入力したログイン情報を受け取って拡張機能内に保存するため。保存したパスワードをページに渡すことはありません。
3. 応募フォームが別のサイトの枠に埋め込まれているときと、ログイン情報を保存したマイページのサイトでだけ、利用者の許可を得てから入力するため（optional_host_permissions。最初からすべてのサイトに入れる権限は持ちません）。

## リモートコードの使用

「いいえ、リモートコードを使用していません」を選ぶ（実行するコードはすべてパッケージに含まれる。サーバーから受け取るのは判定結果と広告の文言・リンクの JSON だけ）。

## データの使用（ダッシュボードのチェック項目）

- 収集するデータ：「ウェブサイトのコンテンツ」（応募フォームの入力欄の見出し・ラベルなど）
- 「認証情報」：マイページのログイン情報を利用者のブラウザ内にだけ保存する（運営者には送信しない）
- 個人を特定できる情報・連絡先・位置情報などは収集しない（プロフィールは端末内にのみ保存）
- 次の3点に同意する
  - 承認されたユースケース以外の目的で第三者に販売・転送しない
  - 拡張機能の単一用途と関係のない目的で使用・転送しない
  - 信用力の判断や貸付の目的で使用・転送しない
