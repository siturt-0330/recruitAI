デベロッパーダッシュボードの各欄に、そのまま貼り付けて使う。

## 名前

らくらくエントリー｜就活エントリー自動入力

## 概要（132文字以内）

ダッシュボードでは編集できず、`wxt.config.ts` の `manifest.description` が使われる。変えるときはそちらを直して zip を作り直す。

就活の応募フォームを、登録したプロフィールでワンクリック入力。氏名・フリガナ・生年月日・住所・学歴まで、和暦や全角半角も自動で合わせます。

## 説明

就活のエントリーシートや応募フォーム、何度も同じことを入力していませんか？
らくらくエントリーは、一度登録したプロフィールを、企業ごとに違う応募フォームへワンクリックで入力する Chrome 拡張機能です。

■ できること
・氏名、フリガナ、ローマ字、生年月日、性別
・住所（郵便番号・都道府県・市区町村・番地・建物名）、帰省先、緊急連絡先
・電話番号、メールアドレス
・学校区分、大学名、学部・学科、入学・卒業年月、高校
・運転免許、TOEIC などの資格、趣味・特技 など

■ フォームに合わせて自動で変換
・和暦／西暦、全角／半角、カタカナ／ひらがな
・電話番号や郵便番号の分割欄、ハイフンのあり・なし
・年・月・日が分かれたプルダウンや、デザインされた独自のプルダウン

■ 入れたところがひと目で分かる
入力した欄には「済」の印が付きます。自信がない欄は「確認」と表示されるので、送信前にそこだけ見直せば大丈夫です。「元に戻す」で入力前の状態にも戻せます。

■ AI「Sophon」が判定を手伝います
ルールで分からなかった欄だけ、AI が見出しから判断します。API キーの設定は不要で、そのまま使えます。

■ プライバシー
プロフィールはあなたのブラウザの中にだけ保存します。AI の判定に送るのは入力欄の見出しだけで、名前や住所などの中身は送りません。

■ 使い方
1. アイコンから「プロフィールを作成」で登録
2. 応募フォームを開いて、アイコンの「このページに入力」（または Alt+Shift+F）

※ 送信前に、入力内容を必ずご確認ください。
※ 現在はすべての機能を無料で使えます（今後、有料プランを追加する予定です）。
※ ポップアップに「PR」表示の広告枠があります。

## 単一用途の説明（Single purpose）

就職活動の応募フォームに、利用者が登録したプロフィールを自動で入力すること。

## 権限の理由

| 権限 | 理由 |
| --- | --- |
| activeTab | 利用者がアイコンかショートカットで入力を指示したタブにだけ、入力処理を実行するため |
| scripting | 指示されたタブの応募フォームを読み取り、入力するスクリプトを実行するため |
| storage | プロフィール・設定・マイページのログイン情報を、利用者のブラウザ内に保存するため |
| 任意のホスト権限（optional_host_permissions） | 応募フォームが別のサイトの枠に埋め込まれているときと、マイページのログイン情報を保存したサイトでだけ、利用者の許可を得て入力するため |
| ホスト権限（中継 API の URL） | ルールで判定できなかった入力欄を、運営者の API で AI に判定させるため。送るのは入力欄の見出しなどの構造だけ |

## リモートコードの使用

使用していない（実行するコードはすべてパッケージに含まれる。サーバーから受け取るのは判定結果と広告の文言・リンクの JSON だけ）。

## データの使用（ダッシュボードのチェック項目）

- 収集するデータ：「ウェブサイトのコンテンツ」（応募フォームの入力欄の見出し・ラベルなど）
- 「認証情報」：マイページのログイン情報を利用者のブラウザ内にだけ保存する（運営者には送信しない）
- 個人を特定できる情報・連絡先・位置情報などは収集しない（プロフィールは端末内にのみ保存）
- 次の3点に同意する
  - 承認されたユースケース以外の目的で第三者に販売・転送しない
  - 拡張機能の単一用途と関係のない目的で使用・転送しない
  - 信用力の判断や貸付の目的で使用・転送しない
